# ルビ辞書

この一覧に単語を追加すると、ゲーム内でルビ（ふりがな）が自動で付きます。

## 書き方

- **読み**：単語全体の読みをひらがなで書く（例：`まほう`）
- **区切り読み**：各文字に個別のルビを付けたい場合は `｜` で区切る（文字数と一致させること）
- **表示**：`毎回`（出るたびに表示）または `初回のみ`（最初の1回だけ表示）。省略すると `毎回`
