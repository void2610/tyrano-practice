# シナリオライター向け記法ガイド

この記法で書いた原稿は、AI（Claude Code）が自動的にゲーム用スクリプトに変換します。

---

## コメント

`;` で始まる行はメモとして扱われ、ゲーム中には表示されません。

```
; ここは朝のシーン。BGMは未定...
```

---

## セリフ

`#キャラクター名` の次の行からセリフを書きます。キャラクター名は日本語でOKです。

```
#あかね
おはようございます！
今日もいい天気ですね。
```

セリフブロック内に空行を入れると、そこでクリック待ちになります。

```
#あかね
おはようございます！

今日もいい天気ですね。
```

---

## 地の文（ナレーション）

`#` を名前なしで書くと地の文になります。

```
#
静かな朝の教室。
窓の外では小鳥がさえずっている。
```

---

## ト書き（演出指示）

`@` で始まる行に日本語で演出を指示します。書き方は自由です。AIが解釈して変換します。

```
@ 背景を「classroom_morning.jpg」に切り替える（1秒）
@ BGMを「morning.ogg」に変更する（70%音量）
@ あかねが登場する
@ あかねが笑顔に変わる
@ BGMをフェードアウトする（2秒）
@ 画面を暗転させる
@ 少し間を置く
```

ファイル名が決まっていない場合は省略するか曖昧に書いておいてもOKです。AIが推測して変換します。

---

## 選択肢

`?` で始まる行が選択肢になります。`->` の後にジャンプ先のラベル名を書けます。

```
? 助けに行く -> help
? 無視する -> ignore
```

ジャンプ先は省略してもOKです。AIが文脈から推測します。

---

## キャラクター名（chara_list.md）

原稿で使うキャラクター名と備考を `chara_list.md` に記載します。

| 原稿での書き方 | 備考 |
|---|---|
| あかね | ヒロイン |
| やまと | 主人公 |

新しいキャラクターを追加するときはこの表に行を追加してください。

---

## ルビ辞書（ruby_list.md）

ゲーム内で自動的にルビ（ふりがな）を付けたい単語を `ruby_list.md` に記載します。原稿にはそのまま漢字で書くだけでOKです。

### 一括ルビ（単語全体に読みを付ける）

| 単語 | 読み | 表示 |
|---|---|---|
| 魔法 | まほう | |
| 召喚陣 | しょうかんじん | 初回のみ |

### 区切りルビ（各文字に個別の読みを付ける）

読みの列に `|` で区切って書きます。**文字数と区切り数を一致させてください。**

| 単語 | 読み | 表示 |
|---|---|---|
| 自動人形 | オ｜ート｜マ｜タ | |

### 表示タイミング

- 空欄または省略 → 出るたびに毎回表示
- `初回のみ` → ゲーム中で最初の1回だけ表示

---

## よくある質問

**Q. ファイル名がわからない場合は？**
省略するか「朝っぽいBGM」「教室の背景」のように書いておいてもOKです。AIが推測して変換し、開発者が後で確認します。

**Q. ルビ（ふりがな）を付けたい場合は？**
`ruby_list.md` に単語を追加してください。原稿にはそのまま漢字で書くだけでOKです。

**Q. キャラクターを追加したい場合は？**
`chara_list.md` に行を追加してください。

**Q. 対応していない演出は？**
`@` で自由に書いておけばAIが解釈します。どうしても変換できないものはコメントとして残されるので、後で開発者が対応します。

## 変換例

**原稿:**

```
; 朝の教室シーン

@ 背景を「classroom_morning.jpg」に切り替える（1秒）
@ BGMを「morning.ogg」に変更する（70%音量）

#
朝の光が差し込む教室。
まだ生徒の姿はまばらだった。

@ あかねが登場する

#あかね
おはようございます！

今日の授業、楽しみですね。

#やまと
ああ……まあな。

? 応援する -> cheer
? そっとしておく -> ignore
```

**変換後:**

```
; 朝の教室シーン

@bg storage="classroom_morning.jpg" time="1000"
@playbgm storage="morning.ogg" volume=70 loop=true

#
朝の光が差し込む教室。[r]まだ生徒の姿はまばらだった。[p]

[chara_show name="akane" time="600"]

#akane
おはようございます！[p]

#akane
今日の授業、楽しみですね。[p]

#yamato
ああ……まあな。[p]

[glink text="応援する" target="*cheer"]
[glink text="そっとしておく" target="*ignore"]
[s]
```
